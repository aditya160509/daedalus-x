# A11 — Consolidate overlapping inspection/editor controls

**Status:** built. Every inventoried action is still reachable, from one side panel instead of a
floating toolbar plus a duplicated design picker.

## Inventory before the change

| Action | Old location | New location |
| --- | --- | --- |
| Choose design | Studio header select **and** floating viewport select (duplicate) | Studio header select only; it now feeds Inspect as `designId` |
| Import GLB / replace | Viewport panel header | unchanged |
| Save CAD as design | Studio header (CAD tab) | unchanged; it is the CAD→design direction, not a duplicate |
| Render mode | Floating toolbar | Side panel → Viewport |
| Camera presets | Floating top-right strip | Side panel → Viewport → Camera |
| Exploded view | Floating toolbar | Side panel → Viewport |
| Turntable | Floating toolbar | Side panel → Viewport |
| Section plane + position | Floating toolbar | Side panel → Viewport |
| Dimensions | Floating toolbar | Side panel → Viewport |
| Measure between two points | Floating toolbar + HUD readout | Side panel → Viewport; HUD stays as the readout |
| Compare + comparison design | Floating toolbar + floating select | Side panel → Viewport |
| Save PNG snapshot | Floating toolbar | Side panel → Viewport |
| Part tree, isolate, visibility, inspector | Side panel | unchanged |

The old floating toolbar was removed from the viewport. The measure HUD remains because it is a
readout, not a second control set. The single design picker removes the state split where the
header could point at one design while Inspect still showed the first listed design.

## State and layout

- Inspect mounts once and stays mounted while other Design Studio tabs are shown, so part
  selection, camera, measure state and hidden parts survive Rules → Inspect round-trips. CAD keeps
  its own iframe and is unchanged.
- Below 900 px the resizable viewport/sidebar pair switches to a vertical split, so the side panel
  does not squeeze the viewport to an unusable width at 375 px. The side panel scrolls; the part
  tree keeps its own scroll area.
- URLs are unchanged: `/design?design=<id>#inspect` still selects the design and opens Inspect.

# F08 — Required-sample-size solver

**Status:** software complete; field validation remains a data gate.

## What changed

- `src/daedalus/paired.py`: `PairedRequest.meaningful_effect_ms` (optional, 0 < effect ≤ 10 s).
  When supplied, `_required_pairs` returns the smallest pair count in [3, 1000] whose two-sided
  noncentral-t power reaches `target_power`. The result carries:
  - `required_pairs` (int or null),
  - `required_pairs_status` (`ok`, `not_requested`, or an explicit out-of-bounds reason),
  - `power_at_required` and `power_below_required`.
  By construction N meets the target and N−1 does not; if even 1000 pairs miss the target the
  answer is `null` with `target power is not reached within 1000 pairs`, not a rounded-up lie.
- `apps/cockpit/src/lib/api.ts`: response schema and request type updated.
- `apps/cockpit/src/components/race/PairedTimingPanel.tsx`: a "Meaningful difference (0 = skip)"
  field in ms, a Required pairs metric, and a caption stating the N / N−1 power comparison. Empty
  effect shows "Enter a meaningful difference to solve for N" rather than a fabricated number.

The solver reuses the existing SciPy noncentral-t power, the same alpha/target-power fields, and
the pilot difference SD. Required N is a planning estimate under independent, approximately normal
paired differences; it is not a guarantee of a future result.

# T06 — AETHER Wind Tunnel: commercial-grade visuals
**Model:** DeepSeek V4.1 Flash Free · **Date:** 2026-11-01 · **Status:** review

## Built
- **Scene** (`apps/cockpit/src/components/viewer/flow/FlowScene.tsx`): ACES Filmic tone mapping, sRGB output, drei `Environment resolution={256}` built from three `Lightformer` panels (no HDR download), hemisphere + key light, contact shadows, `SMAA` + `Bloom` (`luminanceThreshold 0.85`, `intensity 0.6`, `mipmapBlur`) from `@react-three/postprocessing`, and a drei `PerformanceMonitor` that drops post-processing after a sustained decline below 45 fps. Effects are also skipped when the conservative GPU-memory estimate exceeds the 600 MiB budget. Context-loss remount preserved.
- **Pressure skin** (`PressureSkin.tsx`): 16-band Cp quantisation with `fwidth`-antialiased isolines in a `MeshPhysicalMaterial` (clearcoat 0.3, roughness 0.45), smooth/banded toggle, plain and darkened modes, pointer probe.
- **Smoke streams** (`SmokeStreams.tsx`): `LineSegments2`/`LineMaterial` at 1.5 px, speed colouring, depth fade, ~1 Hz emissive head pulse, density subsampling in a module Web Worker (`flow.worker.ts` + `flowMath.packLines`).
- **Wake scanner** (`WakeScanner.tsx`): 24 exported x-planes scrubbed by slider; active plane opaque, neighbours ±1 ghosted at 0.12; Ux/U∞ ↔ Cp0 scalar switch; x position in mm.
- **Flow arrows** (`FlowArrows.tsx`): one `InstancedMesh` of cones, grid-subsampled from the active plane, scaled and coloured by in-plane velocity (`flowMath.arrowSamples`).
- **Vortex cores** (`VortexCores.tsx`): translucent Q iso-surface (opacity 0.35), speed colouring, two exported levels (Q 50 / Q 200, normalised by (U∞/L)²) selected in the shader.
- **Oil flow** (`OilFlow.tsx`): thin light surface streaks over the darkened car plus red separation discs and a legend entry naming the heuristic.
- **Sensitivity map** (`SensitivityMap.tsx`): optional T05 layer rendered on the car with a diverging map and the requested push-out wording; the rail disables it when the run has no adjoint result.
- **Split compare** (`CompareView.tsx`, `useDeltaSurface.ts`): second-run picker, side-by-side with a shared camera bus, or ΔCp on run A's topology. Topology changes are mapped by a worker KD tree (`flowMath.nearestDelta`); the legend states "nearest-vertex mapping" and the RMS distance in mm.
- **Fly-through / WebM** (`FlyThrough.tsx`): 12 s CatmullRom nose-to-wake path, play/pause, `canvas.captureStream` + `MediaRecorder` download, and a canvas-drawn provenance stamp (`SourceStamp.tsx`) because HTML overlays are absent from the capture.
- **Control rail + HUD** (`ControlRail.tsx`, `LayerOptions.tsx`, `ViewerHud.tsx`): grouped Surface / Volume / Planes icon rail with tooltips and disabled reasons, contextual seed-density slider, animation toggle, wake plane slider/scalar, Q level, camera presets, FPS/draws/memory/effects readout, one legend stack (min/mid/max + units), cursor-following probe, rejected-run banner, error chip and status line.
- **Drag build-up** (`apps/cockpit/src/components/charts/DragBuildupChart.tsx`): stacked-area ECharts plot of cumulative ΔCd by component group, with total/reference/error in the header; hover emits the x position and moves the linked 3D marker plane (`updateAxisPointer`/`globalout` added to `useECharts`).
- **Motion preference** (`src/lib/motion.ts`): `useReducedMotion` via `useSyncExternalStore`; stream pulses, belt scroll, fly-through and recording are disabled when the OS asks for reduced motion.
- **Data decode** (`src/lib/api.ts`): typed views share one immutable buffer; validates alignment, extents, index bounds, monotone offsets and sentinel values; decodes `vectors`, per-layer `scalars`/`ranges`, xslices, oil flow, separation, vortices, wake shell and sensitivity.
- **Export additions** (`src/daedalus/viz/insights.py`): writes `Q_level` alongside `speed_ratio` on the vortex surface and in-plane `U` vectors on every wake slice so the two-level toggle and arrows use solved data rather than a client-side approximation.
- Removed the old `apps/cockpit/src/components/viewer/FlowViewer.tsx`; the viewer is now the split `flow/` folder and `src/app/simulate/FlowPanel.tsx`.

## How to run / see it
```bash
uv run daedalus-api                 # :8000
pnpm --dir apps/cockpit dev         # :3000 → /simulate
```
Pick a run with an export (`orbit_baseline_20ms` currently has one). Toggle layers in the left rail; open Compare from the rail; hover the build-up chart; press `F`, `R`, `Space` for full screen, camera reset and animation.

## Decisions and deviations
- **Compare default is ΔCp, not side-by-side.** Delta is the question the team actually asks; side-by-side remains one click away and shares the camera bus.
- **ΔCp is p99-normalised and symmetric.** Outliers cannot flatten the map, and zero always reads as white. The legend states the mapping method and RMS distance; it is a display normalisation, not a predicted Cd change.
- **Global F/R/Space shortcuts.** The UI bar asks for them; the handler ignores inputs, selects, textareas, buttons and content-editable targets so typing is never hijacked. This replaced a focus-trapped `tabIndex` that failed the accessibility lint.
- **Effects, not geometry, degrade first.** Below 45 fps for 2 s the composer is removed. Data density never changes silently.
- **Belt stripes widened to 0.12 m** and scroll at `0.02·U∞` so 20 m/s does not strobe at 60 Hz; the motion is still proportional to freestream speed.
- **Wake plane scalar uses the exported `ranges`** rather than the global mesh range, so Cp0 and Ux/U∞ legends stay honest.
- **No sensitivity layer is fabricated.** The rail disables it and says no adjoint result exists.

## Known gaps (for reviewer)
- No browser or visual QA was run, per the build pack. Visual fidelity, 60 fps at 1440p, actual GPU memory and the 16 ms frame budget still need eyes and a profiler.
- `orbit_baseline_20ms` is a rejected run; the viewer shows its rejection banner. Its export is v2 and includes every layer except sensitivity, so it is the best available fixture.
- The nearest-vertex delta mapper is only meaningful when the two surfaces roughly coincide; it reports RMS distance but does not reject a bad match.
- Drag build-up hover is linked to the marker plane, but reverse linked selection (clicking 3D to move the chart) is not implemented.
- Recording requires `canvas.captureStream` + WebM support; unsupported browsers get an explicit error chip.

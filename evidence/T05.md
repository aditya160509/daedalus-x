# T05 — Frozen-turbulence drag adjoint
**Model:** Codex (GPT-6) · **Date:** 2026-11-01 · **Status:** in-progress — runtime acceptance gated

## Built
- `src/daedalus/adjoint.py`: quality-gated isolated case preparation, documented single-point drag objective, frozen primal/turbulence, 1,000 adjoint iterations, matching Ua/pa conditions and numerical dictionaries, rank-capped serial/parallel launch, scalar field discovery and residual-reduction report.
- `daedalus adjoint prepare/run/export`, immutable `AdjointResult` in contracts, plus `viz/sensitivity.py` and optional frontend schema for a mirrored, symmetric, p99-normalised outward-normal sensitivity layer.
- Original primal files are never edited. Preparation refuses existing destinations, rejected/mesh-failing cases and un-reconstructed solutions. Solver execution takes the jobs worker lock and checks for surviving CFD processes; it cannot execute queued grid-study cases.
- Missing/unconverged sensitivity remains explicitly unavailable. No artificial nose/wheel/wing map is generated.

## How to run / see it
After obtaining a mesh-passing, accepted or pending-review primal:
```bash
uv run daedalus adjoint prepare data/runs/PRIMAL
uv run daedalus adjoint run data/runs/PRIMAL_adjoint --procs 8
uv run daedalus adjoint export data/runs/PRIMAL_adjoint
```
Use `prepare --out NEW_PATH` for a new attempt; an attempted result is not overwritten. The copied case's manifest records the primal path/hash/time and assumptions; the result records execution success separately from residual convergence. Export uses the discovered scalar face sensitivity at its recorded time, interpolated to surface vertices.

## Decisions and deviations
- Read the installed v2606 motorBike sensitivity tutorial first, then the official manual. The objective is documented `type force`, not a nonexistent `forceCoeffs` objective keyword. Both `surfacePoints` and scalar face maps are configured, following the tutorial's multiple-map approach.
- OpenFOAM's normal points into the car; negate it for outward-car dCd/dn. IncludeSurfaceArea=false yields a surface-area-normalised distribution; the displayed p99 normalisation is not a predicted finite design-change Cd.
- Run the declared fixed 1,000 iterations. A map is exportable only when all Ua components and pa drop at least three orders (or stay at numerical zero); absent/nonfinite residuals fail closed.
- The original primal acceptance is retained. Frozen turbulent viscosity, the saved steady RANS snapshot and fixed moving-wall boundary conditions are explicit approximations.

# T16 timestamps and T21 structural analysis
**Model:** Claude (Jainam's session, branch `next-wave`) · **Date:** 2026-11-02 · **Status:** review

## Built
- `src/daedalus/anchor.py` (T16): builds an RFC 3161 TimeStampReq for the SHA-256 of a sealed prediction's manifest, posts it to a timestamp authority (default `https://freetsa.org/tsr`, https only), checks the reply is granted and carries our hash and nonce, reads the authority's time, and stores the reply in the evidence store as an `rfc3161_timestamp` artifact. `verify_command` prints the `openssl ts -verify` line a judge runs to check the signature. Only the hash leaves the machine.
- `src/daedalus/structure.py` (T21): Euler-Bernoulli beam finite elements with fixed and pinned supports, point and distributed loads, rectangle, circle and tube sections. Returns deflection, bending moment, peak bending stress and a safety factor. `RULE_LOAD_TESTS` records the scrutineering load tests (T6.3 tether guide 200 g, T7.13 wheel 100 g, T4.4.5 halo 1 kg). `MATERIALS` holds handbook values marked `estimated`; the model block foam is left out because it must be measured.
- `tests/test_anchor.py` (7 tests, fake timestamp authority, no network) and `tests/test_structure.py` (8 tests against textbook solutions: PL³/3EI, 5wL⁴/384EI, PL³/192EI).

## Checks
- `ruff check` and `ruff format`: clean. `pyrefly check` (strict): 0 errors on both modules.
- `pytest tests/test_anchor.py tests/test_structure.py tests/test_predictions.py`: all pass.

## Decisions and deviations
- The timestamp reply's content is checked (status, our hash, our nonce, a time). The CMS signature is not verified in Python because that needs a crypto dependency; `openssl ts -verify` does it with the authority's certificate.
- Beam elements, not 3D FEA: the parts the rules load are slender, and a beam model is checkable by hand. 3D FEA (CalculiX) stays on the plan for chunky parts.

## Known gaps (for reviewer)
- No real timestamp has been requested yet; run `anchor_prediction` once against freetsa.org and keep the `.tsr`.
- No API route or UI for either module.
- Material values are estimates. Measure the model block foam (or get the datasheet) before quoting any safety factor for the body.

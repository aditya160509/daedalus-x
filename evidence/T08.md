# T08 — TITAN race experience

**Model:** Claude (Codebuff) · **Date:** 2026-11-01 · **Status:** review

## Built
- Telemetry Wall (ATLAS-style), all in `apps/cockpit/src`:
  - `components/charts/TelemetryChart.tsx` — stacked synced ECharts sub-plots (velocity, accel, thrust/drag/rolling, distance) with a shared cursor, axis pointer link, Monte-Carlo p5–p95 band fill on the velocity channel, burn-end/finish markers and per-channel y-zoom (`yZoom` map, dataZoom inside).
  - `app/race/RaceWorkspace.tsx` — the workspace grid: metrics row, telemetry panel, cursor panel, replay, spread and ghost panels; 120 ms debounced sim/MC requests (`lib/useDebouncedValue.ts`), cursor clamped to the run.
  - `components/race/ChannelPicker.tsx` — show/hide + drag reorder + per-channel y-zoom reset.
  - `components/race/CursorTable.tsx` — right-hand readout per shown channel at the cursor, plus cursor A/B with Δt/Δvalue.
  - `components/race/raceMath.ts` — cursor interpolation (refuses out-of-range), keyboard step clamping, Δt/Δvalue math, ghost Δt(x) inversion of the distance trace, signed finish gap, replay position clamping. Unit tests in `raceMath.test.ts`.
- What-if sliders: `app/race/RaceInputs.tsx` + `components/race/SliderField.tsx` — mass, CdA, Crr, thrust scale numeric field + shadcn slider; sweep via `components/race/whatIf.ts` (15-point sweep at n=200 through the Monte-Carlo API, staggered/aborted correctly), rendered as `components/race/SweepSparkline.tsx` (race time vs parameter).
- Spread Fan: `trajectory_band: true` support.
  - `src/daedalus/montecarlo.py` — records v(t) at a 200-point common time grid during RK4 and analytically during coast (no extra solves); returns `TrajectoryBand` with p5/p50/p95.
  - `src/daedalus/api/race.py` — `/v1/race/montecarlo` accepts `trajectory_band: bool` and returns the band alongside percentiles.
- Race Replay (3D): `components/race/RaceTrackScene.tsx` (20 m track, lane, start/finish gates, 5 m markers) and `components/race/RaceReplay.tsx` (0.25×–4× playback, side-following camera, two-way cursor link, ghost lane when a second trace exists).
- Ghost race: `components/race/GhostPanel.tsx` — pick a saved preset or a manual CdA for the far lane; finish gap in ms, Δt(x) chart, always-running ghost query (manual CdA default).
- Presets: `components/race/presets.ts` (+ `PresetPanel.tsx`) — save/rename/delete what-if configurations in `localStorage` inside try/catch, guarded against SSR and duplicate names.

## How to run / see it
- Backend: `uv run uvicorn daedalus.api.app:app` (or `daedalus-api`).
- Cockpit: `cd apps/cockpit && pnpm dev`, open `/race`. Move sliders, hover/arrow-key the telemetry, double-click drag A/B cursors, replay, and set ghost options in the far-lane panel.

## Decisions and deviations
- Sweep runs at n=200 per spec but respects the spec sentence "on drag-end": the sweep engine aborts superseded requests rather than queueing 15 solves per drag event.
- Ghost defaults to a manual CdA run so the ghost lane is always live; presets select real configurations when one is chosen.
- Cursor and delta ranges clamp to the simulated run end instead of scrolling out into blank chart space.

# T03 — Fixed-domain grid and speed study
**Model:** Codex (GPT-6) · **Date:** 2026-11-01 · **Status:** review

## Built
- `src/daedalus/gridstudy.py`: three-resolution plan (base ratio 1.5), medium-mesh speeds 15/20/25 m/s with 20 m/s reused, queued submission, conditional general Richardson/GCI and log-Re regression. Oscillatory/divergent/indeterminate data cannot produce fabricated p or GCI.
- `src/daedalus/cfd.py`: template v3 adds fixed domain rounding, independent of the varying base-cell spacing. All study cases use averaged acceptance. Effective 3D cell-count spacing is used for reported refinement ratios.
- CLI `daedalus grid submit/report`, `/v1/studies` and `/v1/studies/{id}`, typed frontend schemas and Simulate grid/speed panel with CI segments, extrapolated reference, GCI colour thresholds and per-run quality.
- T02's validated CFD job/CLI accepts optional base-cell/domain-cell/acceptance overrides. No second execution system or dependency.

## Decisions and deviations
- No campaign ran: the hard resource restriction takes precedence. Queued five quick-derived cases under a worker-exclusive lock, then verified all remain queued. The medium 20 m/s case is shared, so the plan needs five rather than six runs.
- Changing only the background spacing previously changed the rounded domain too. Added `domain_cell_m` to hold the physical domain fixed and bumped template v3, preserving existing case artifacts.
- snappy cell counts need not refine at exactly 1.5 even when base spacing does; report uses effective N^(-1/3) ratios and supports unequal refinement. Unsupported ratios/differences are explicit indeterminate outcomes.
- Numerical pending-review runs may enter conditional analysis only if mesh/mean gates pass. Rejected/missing cases remain visible but excluded. A green GCI badge is numerical uncertainty, not official acceptance or physical validation.
- Speed fit reports whether zero lies in its slope interval, explicitly meaning an effect is not resolved, not proven invariance. The declared mean-CI uncertainty supplies a floor even if three points lie on an exact line.
- **Exact Celik et al. (2008) Table 1 verification is missing**: DOI was bot-blocked and the publisher/NRC PDFs could not be fetched; a mirror returned a challenge. Used the independently accessible NASA worked example and an exact unequal-grid analytic fixture, without pretending these are that table. Reviewer should verify the requested original table before acceptance.

# T01 — CFD accuracy: axle rotation, explicit mesh quality and averaged acceptance
**Model:** Codex (GPT-6) · **Date:** 2026-11-01 · **Status:** review

## Built
- `src/daedalus/geometry.py`: schema v2 reports front/rear axle origins, axes and exact solid bounding-box radii. Writes axle-specific CFD surfaces while preserving the parent `wheels` semantic/force group. Existing geometry revisions cannot be overwritten, preventing stale parent-wheel STLs from being meshed alongside split surfaces.
- `src/daedalus/cfd.py`: template `daedalus-halfcar-v2`, rotatingWallVelocity with signed angular rate, explicit local meshQualityDict and requested snapping controls. Missing axle metadata retains noSlip and a manifest warning. Failed checkMesh stops before the solver and remains rejected.
- Averaged mode defaults for wheel geometry, with a 500-sample/10-batch Student-t interval and positive lag-1 batch-correlation inflation; the strict steady spread gate remains available. Result JSON includes `cd_mean`, `cd_ci95`, `cd_window_spread`, `acceptance_mode`. In averaged mode `cd`, `cl` and component forces use matching windows, and missing/misaligned/non-finite force histories reject.
- Minimum 1000 iterations before early stopping in averaged mode (grouped runTimeControl conditions); SIMPLE residualControl cannot bypass this minimum. The quick cap is now 1200 because its old 800 cap could never reach the required minimum.
- `src/daedalus/cli.py`: `--acceptance-mode steady|averaged` exposes the strict gate without changing UI layout.
- `apps/cockpit/src/lib/api.ts` plus `api.test.ts`: optional averaging fields read legacy results and preserve new statistics.
- `tests/test_geometry.py`, `tests/test_cfd_case.py`: real small STEP import, axle grouping/radii, contact-point cross product, parsed mesh dictionaries, AR(1) interval, steady/averaged acceptance, legacy fallback and failure cases.

- Radius comes from the source solid's engineering-z bounding extent, avoiding tessellation-dependent angular rates; larger wheel solids define radius when bushes share a group. This release assumes two circular axle families, not arbitrary wheel layouts.
- +y × -z = -x, so omega is **negative** for the task's +x moving ground. Manifest uses the task's magnitude wording omega=U/r; the boundary and cross-product test preserve the sign.
- `cd_ci95` is a two-element [lower, upper] interval. Its lag correction uses correlation of the ten batch means (not a second correction applied to raw-sample correlation); negative estimates cannot shrink the interval. This is approximate numerical iteration uncertainty, not physical turbulence coverage.
- The early-stop average test is not the scientific CI gate. Final acceptance still evaluates the full 500-sample history, independently of why the solver terminated.
- Added CLI selector and a small frontend contract test beyond the task's initial file list because strict-mode access and old/new JSON compatibility are part of the requested shared contract. No UI layout changed; no dependency added.
